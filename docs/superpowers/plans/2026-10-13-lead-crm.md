# Lead-to-CRM Automation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task; use superpowers:requesting-code-review for independent review.

**Goal:** Demonstrate validated lead assessment, human approval, HubSpot synchronization, optional Instantly enrollment, and replay-safe campaign events.

**Architecture:** Python standard-library engine with SQLite and a durable operation queue. Provider adapters support explicit demo mode and environment-configured live APIs. n8n is the orchestration entry point, forwarding authenticated requests to the same engine used by the CLI.

**Tech Stack:** Python 3.11+, sqlite3, urllib, http.server, unittest; n8n webhook and HTTP Request nodes.

**Spec:** `docs/superpowers/specs/2026-10-13-lead-crm-design.md`

## Global constraints

- Fictional sample data only; no credentials in Git, exports, or evidence.
- Explicit demo/live mode stored in SQLite; never reuse demo receipts as live receipts.
- Evidence quotes must match supplied source text; unknowns remain unknown.
- Human approval and contact verification before outreach.
- Unique email, event, and operation keys; suppression cannot be undone by late events.
- Uncertain remote writes require reconciliation before retry.
- Local authenticated HTTP server only; no public deployment.
